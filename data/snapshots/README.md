# Golden snapshots

Committed, dated fixtures generated by `scripts/refresh_snapshots.py`. They exist so
this repo produces the same answer for anyone who clones it, at any time, without
network access or a Trellis install.

**This directory is intentionally empty until snapshots are generated on a machine with
SEC EDGAR access.** No synthetic or placeholder data is committed here: a plausible-
looking fake in a directory named "snapshots" is worse than an empty directory, because
a reader has no way to tell it isn't real.

To populate:

```bash
export TRELLIS_USER_AGENT="Your Name your@email.com"
python scripts/refresh_snapshots.py
```

Snapshots are never refreshed automatically in CI. Changing the numbers must be an
explicit, reviewable commit -- otherwise the fixture is a moving target, not a
reproducibility contract.
