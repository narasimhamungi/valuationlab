# Golden snapshots

Committed, dated fixtures generated by `scripts/refresh_snapshots.py`. They exist so
this repo produces the same answer for anyone who clones it, at any time, without
network access or a Trellis install.

## What's here

Real data, not placeholders — nine companies across the subject and both peer groups:

- **Subject:** JNJ
- **Pharma peer group** (Innovative Medicine leg): PFE, MRK, ABBV, BMY
- **MedTech peer group** (MedTech leg): MDT, BDX, SYK, BSX
- **Market snapshot:** share price and share count for all nine, in `market.json`

**Abbott Laboratories (ABT) is deliberately absent.** Its ingestion fails on nine fields
across every year 2020-2025 through Trellis — a broader data-availability problem, not a
missing tag this project's fixes address. `run_valuation.py` excludes it explicitly and
reports why, rather than silently dropping it.

Each `<TICKER>_financials.json` records its own `generated` date and `base_year` — check
those fields directly rather than trusting a date written into this file, which would go
stale the next time snapshots are regenerated and this README isn't.

## Regenerating

```bash
export TRELLIS_USER_AGENT="Your Name your@email.com"
python scripts/refresh_snapshots.py
```

A partial failure (a peer whose ingestion breaks) still writes everything that
succeeded and reports the failure by name — it does not silently produce an incomplete
set. Review the diff before committing: snapshots are never refreshed automatically in
CI, because changing the numbers should be an explicit, reviewable commit, not a moving
target masquerading as a reproducibility contract.

## Regenerating financial data without touching market data

```bash
python scripts/refresh_snapshots.py --skip-market
```

Financial snapshots (annual, filing-derived) go stale far more slowly than market data
(daily), so there's a flag to refresh them independently. There's no equivalent
market-only flag — for a quick current price without re-pulling every filer's financials,
call `get_market_data(..., prefer_live=True)` directly instead of running this script.
